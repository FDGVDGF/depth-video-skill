# 四步完整流程

## 第 1 步：准备工具

`bash install.sh` 装好后，用一小段视频测试，导出 MP4 检查人物完整性。示例输出：`examples/test-seg1-depth.mp4`。

## 第 2 步：转黑白深度视频

触发：发视频说“转成黑白深度视频”。

1. `bash scripts/run_depth.sh 输入.mp4 输出.mp4`
2. 保留原比例、时长和声音。
3. 抽帧检查人物有没有明显缺失。
4. 先导出视频，再发提示词。

## 第 3 步：整理视频生成提示词（只写，不生成）

触发：上传人物图、场景图和黑白深度视频，说“写一份完整的视频生成提示词，暂时不要生成视频”。

- 图片1：脸、发型、服装、配饰；图片2：场景、光线、色调；视频1：舞蹈动作、节奏、运镜。
- 人物外观以图片1为准。
- 先观察素材，再提炼主要动作和镜头变化，简洁连贯，不逐秒堆砌。
- 无法读取素材时说明。
- 时长、比例、人数按当次填写的为准。
- 写完就导出提示词：`scripts/export_prompt.py`，出 `.md` 完整版和 `.txt` 纯提示词，正文一字不改。

## 第 4 步：开始生成视频

触发：在同一对话里确认提示词后，说“按刚才确认的提示词和已上传的素材生成视频”。

- 模型、时长、比例、人数按当次填写的为准，模型必须是已配置且支持这些参考的。
- 人物以人物图为准，环境以场景图为准，动作和运镜参考视频。
- 模型不支持某类参考，先说明。
- 完成后保存到指定位置，并给文件路径。
