# 提示词格式（v3，以后都按这个格式）

这是本仓库写视频生成提示词的固定格式，2026-11-08 定稿。以后每次写提示词都按这里来，不要回到简版。

## 1. 先核实，再写

写提示词之前，先按原彩色视频逐帧复核，不要只看深度视频，也不要只凭 2fps 粗抽帧下结论。

- 原片时长以视频流为准，不是深度输出的时长。深度输出可能被音频截短。
- 动作时间点用 10fps 抽帧复核，保留动作之间的过渡，不要只写动作的稳定段。
- 机位、模糊、口型、手部接触、字幕出现和消失的时间，都要以原片帧为准。

## 2. 八条规则

1. 机位不写死冲突的描述。只写可观察的变化，例如“人物在画面中由大变小，取景由近景变为全身，背景随之完整入画”。不要同时写“固定机位”和“镜头拉远”。变焦、机位后移、后期缩放，机制未确认就不写机制。
2. 不把深度图的模糊当成拍摄效果。原片里确实有模糊时，只写“画面从模糊逐渐变清晰”，不写“失焦”。没有原片依据就删除。
3. 明确参考素材的分工。
   - 人物图：身份、五官、发型、服装。
   - 场景图：环境、材质、颜色、灯光。
   - 深度视频：动作时序、人物位置、身体朝向、空间关系、画面尺度变化。
   - 如果没有单独的人物图或场景图，写明人物和场景都取自原片哪一帧，不要假装有单独的图片，也不要在正文里留与人物图冲突的旧服装设定。
4. 动作时间要逐帧复核。写约数，保留过渡，例如“约 2.9-约 3.0 秒双手快速抬起”。不要把过渡段直接跳过。
5. 口型需要依据。深度视频无法可靠确认嘴部细节。不要凭空写“对口型、张嘴说话”。原片里能看到嘴部张开时，只写嘴部状态。要对口型，必须提供指定音频及同步要求。
6. 字幕与生成画面分开。字幕不要写进生成提示词里让模型生成中文大字。原片里确实有的字幕，写明在原片里出现的时间和内容，建议后期添加。
7. 接触与定格不要臆测。手靠近边框时，只写“手掌靠近边框，保持结束姿态”，不要写“扶住”。视频结束时只写“保持结束姿态至视频结束”，不要写“定格”。
8. 先确认模型能力。写明所用模型或工作流是否真正支持深度视频控制，还是仅把它当普通参考视频。“严格跟随”不能保证动作精确复刻。没有已配置且已证实支持深度控制的模型时，写明这一点，深度视频仅作动作时序和人物位置参考。

## 3. 提示词正文结构

按这个顺序写，缺哪一项就写“未确认”，不要编：

1. 人物：身份、五官、发型、妆容、配饰。
2. 服装：上身、腰部、下身、腿部、鞋。
3. 场景：地点、背景、墙面、地面、灯光。
4. 画面规格：比例、时长、人数、取景。
5. 动作时间轴：每一段动作的约数时间、动作、过渡。
6. 模型能力说明：深度视频仅作参考，不保证精确复刻。

## 4. 交付格式

每次交付两个文件，外加说明：

- `<name>.md`：完整版，带模型、时长、比例、人数、三个参考，再加提示词正文。
- `<name>.txt`：纯提示词正文，一字不改，可直接粘贴到视频生成工具。
- 说明里必须分开写两部分：
  - 已确认内容：时长、比例、人数、镜头数、服装和场景细节、动作时间和过渡、字幕在原片里的时间和内容、结尾手的位置。
  - 仍需确认内容：取景变大的机制、模糊的成因、要不要对口型及指定音频、字幕要不要后期加、用哪个支持深度控制的模型生成。
- 不要把推测写成事实。

## 5. 示例

完整示例见 `examples/red-devil-prompt-v3.md` 和 `examples/red-devil-prompt-v3.txt`，提取见 `examples/red-devil-extract.md`。那次的核实过程是：原片 5.37 秒，10fps 抽帧 54 帧，动作时间以 1.7 秒、2.9-3.0 秒、4.3-4.4 秒等过渡点为准。
